# LDPL — Site vitrine

Site statique en HTML, CSS et JavaScript, composé de trois pages : Accueil, À propos et Contact. Le menu latéral s’ouvre depuis les trois traits en haut à droite.

## Prévisualiser
Ouvrir `index.html` dans un navigateur. Les trois pages doivent rester dans le même dossier, avec le dossier `assets`.

## Publier sur GitHub Pages
1. Créez un dépôt GitHub (par exemple `ldpl`).
2. Importez `index.html`, `a-propos.html`, `contact.html`, `style.css`, `script.js` et le dossier `assets`.
3. Dans **Settings → Pages**, choisissez **Deploy from a branch**, branche `main`, dossier `/ (root)`, puis enregistrez.

## Formulaire de contact
Le formulaire valide les champs dans le navigateur mais ne transmet pas encore les messages. Pour recevoir les demandes, connectez-le à Formspree, Netlify Forms ou à votre propre backend.

Les polices Cormorant Garamond et Montserrat sont chargées depuis Google Fonts ; des polices de remplacement sont prévues.
